Watch Out For

impl-1 & impl-3 share graph-generator.ts

Both nodes modify the same file. Mitigated by making impl-3 depend on impl-1, so they run sequentially. But merge conflicts are still possible if impl-1's changes shift line numbers.

Baseline git checkout is slow & risky

tsc-check baseline capture does git stash → checkout → tsc → restore. If interrupted, working tree could be left at wrong commit. Fallback: scope-filter only (no git ops).

Test file convention assumption

deriveTestFiles maps src/foo.ts → src/__tests__/foo.test.ts. Works for this project but fails for non-standard layouts. Falls back to full suite when no mapping found.
